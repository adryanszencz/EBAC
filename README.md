# Exercício Cypress (módulo 34)

Testes E2E da agenda de contatos (https://ebac-agenda-contatos-tan.vercel.app/) com Cypress.

Testes em `cypress/e2e/agenda.cy.js`:

- exibe a lista inicial de contatos
- inclui um novo contato
- altera um contato
- remove um contato

## Como rodar

```bash
npm install
npm test
```
